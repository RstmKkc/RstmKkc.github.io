# BFR PS4 HOST

PS4 için Türkçe kontrol merkezi. Cam görünümlü paneller, mavi ışık efektleri ve sade bir kullanım deneyimi.

**Site: https://rstmkkc.github.io/**

## PS4 üzerinden kullanım

1. PS4 İnternet Tarayıcısı ile siteyi açın.
2. JAILBREAK BAŞLAT düğmesine basın.
3. İlk kullanımda önbellek kurulumunu tamamlayın; tarayıcıyı kapatıp yeniden açın.
4. İşlemi başlatın ve ekrandaki durum bildirimlerini izleyin.

Otomatik başlatma varsayılan olarak kapalıdır. Gelişmiş ayarlardan etkinleştirilebilir. Bilgisayar tarayıcısında arayüz ve ayarlar kullanılabilir; jailbreak işlemi desteklenen PS4 donanımı gerektirir.

## Yerel kullanım

`node bfr-serve.cjs` çalıştırın ve `http://localhost:8080/` adresini açın.

## Kontrol

`node bfr-check.cjs`

Arayüz testleri gerçek PS4 üzerinde jailbreak başarısını doğrulamaz. Gerçek cihaz ve çevrimdışı kullanım testi gereklidir.
